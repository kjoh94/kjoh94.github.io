돌곶이역 근처에서 초등 아이 둘(초4·초2)과 가는 **응봉산 팔각정** 당일 코스입니다. 서울숲은 체력 남을 때만, 점심은 분식·정크 대신 앉아서 먹는 한식으로 잡았습니다.

![돌곶이에서 응봉산까지의 지하철·도보 동선 지도]({{ "/assets/img/eungbong-weekend/route-map.svg" | relative_url }})
*돌곶이 → 신당 → 왕십리 → 응봉 → 팔각정 (서울숲은 선택)*

## 한눈에 보는 하루

| 시간 | 내용 |
|------|------|
| 10:15 | 돌곶이 출발 |
| 10:30–11:15 | 지하철 → 응봉역 1번 출구 |
| 11:15–12:30 | 응봉산 팔각정 (천천히) |
| 12:45–14:00 | 성수에서 점심 |
| 14:00– | 서울숲은 **선택** / 아니면 귀가 |
| ~17:00 | 귀가 시작 → 집 7시 전 |

**풀 코스:** 팔각정 + 점심 + 서울숲  
**라이트:** 팔각정 + 점심만 (아이들 컨디션엔 이게 더 안전)

## 가는 길

1. **돌곶이** 6호선 (응암 방면)
2. **신당** 하차 → 2호선 환승
3. **왕십리** 하차 → 경의·중앙선 (문산/용산 방면)
4. **응봉** 하차, **1번 출구**

역에서 역까지 대략 **35–45분**, 출구에서 산 입구까지 도보 **10–15분**입니다. 바닥 유도선(“응봉산 가는 길”)을 따라가면 됩니다.

## 응봉산 팔각정

동네 언덕 수준(대략 80–95m)이라 초등도 충분히 올라가지만, **나무 계단·데크가 가파른 구간**이 있습니다. 아이 기준 정상까지 **20–35분**, 유모차는 어렵고 운동화·물은 필수입니다. 팔각정 근처 공중화장실이 있어요.

정상에서는 한강과 성수·뚝섬 쪽 시내가 보입니다. 사진 찍고 간식·휴식 시간을 넉넉히 잡으면 좋아요.

## 점심 — 아이들이 먹기 쉬운 쪽

분식·패스트푸드는 빼고, 성수에서 앉아서 먹는 한식으로 잡았습니다.

### 1순위: 말방국밥 성수본점
한우국밥이라 초등 입에도 무난한 편입니다. 주말 **11:00–22:30**, 브레이크 없음. 4인 메인만 대략 4.5–7만 원대.

### 대안: 능동미나리 성수직영점
가족 좌석·유아용 의자 후기가 있지만, **미나리·육회는 아이 호불호**가 갈립니다. 아이들이 먹을 건 **곰탕에 밥**이 제일 안전합니다.

> 서울숲까지 가고 웨이팅을 감수할 때만 **난포**(서울숲 근처)도 후보. 주말 대기가 길 수 있어요.

## 서울숲은 선택

팔각정에서 **용비교** 쪽으로 이어가면 서울숲까지 **도보 20–40분** 가능합니다. 다만 이미 계단을 올랐다 내려온 뒤라, 초등에겐 “추가 걷기”에 가깝습니다.

- 컨디션 좋으면: 잔디·놀이터·사슴 구경 정도 **60–90분**
- 사슴 먹이 판매는 중단된 상태(구경만)
- **16:30–17:00**쯤엔 빠져나와야 7시 귀가에 여유

징징거리기 시작하면 응봉역에서 지하철로 성수·귀가 쪽이 더 편합니다.

## 귀가

성수·왕십리·신당에서 6호선 **신내/봉화산 방면** → 돌곶이.  
**17시 전후**에 움직이면 집 **7시 전**에 들어오기 쉽습니다.

## 체크리스트

- 운동화
- 물·간단한 간식
- 편한 옷 (계단 많음)
- (선택) 서울숲용 여유 체력… 없으면 스킵이 정답
