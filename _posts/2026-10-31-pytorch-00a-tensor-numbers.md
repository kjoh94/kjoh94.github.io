PyTorch를 처음 열면 제일 먼저 만나는 단어가 **텐서(tensor)** 예요. 이름은 거창하지만, 이 글에서는 딱 한 가지로만 생각할게요.

> **텐서 = 숫자를 담은 상자.**

상자 안의 숫자가 어떻게 메모리에 놓이는지(storage, stride 같은 것)는 나중에 [1장](/blog/2026/10/25/pytorch-01-tensor/)에서 다뤄요. 오늘은 상자를 **만들고, 모양을 보고, 칸을 꺼내고, 계산하는 법**만 손에 익히면 충분해요. 신경망이 하는 일은 결국 이 상자들을 곱하고 더하는 것뿐이라서, 여기만 편해지면 다음 글(Linear)이 훨씬 쉬워져요.

준비물은 파이썬과 `pip install torch` 하나예요. GPU는 없어도 돼요. 코드 조각은 전부 그대로 복사해서 돌려 보세요. **직접 돌려 보는 게 읽는 것보다 열 배 빨라요.**

## 1. 상자의 종류: 차원

![스칼라·벡터·행렬·3차원 텐서를 나란히 놓은 그림](/assets/img/posts/2026-10-31-pytorch-00a/fig01.jpg)

*그림 1. 숫자 하나(스칼라), 한 줄(벡터), 표(행렬), 표를 여러 장 겹친 것(3차원 텐서). 모양만 다를 뿐 PyTorch에서는 전부 `torch.tensor`예요.*

텐서는 "숫자가 몇 방향으로 늘어서 있나"로 구분해요. 이 방향의 개수를 **차원(dimension)** 이라고 불러요.

- **0차원 (스칼라)**: 숫자 하나. 예: 온도 `23.5`
- **1차원 (벡터)**: 숫자 한 줄. 예: 한 사람의 [키, 몸무게, 나이]
- **2차원 (행렬)**: 표. 예: 여러 사람의 [키, 몸무게, 나이]를 줄줄이 쌓은 것
- **3차원 이상**: 표를 여러 장 겹친 것. 예: 흑백 사진 여러 장, 문장 여러 개

```python
import torch

s = torch.tensor(7.0)
v = torch.tensor([1, 2, 3, 4])
m = torch.tensor([[1, 2, 3],
                  [4, 5, 6]])

print(s, s.ndim)   # tensor(7.) 0
print(v, v.ndim)   # tensor([1, 2, 3, 4]) 1
print(m, m.ndim)   # 2
```

`ndim`은 "몇 차원이야?"를 물어보는 속성이에요. 대괄호 `[`가 몇 겹으로 열리는지 세어 봐도 똑같은 답이 나와요. `[[1,2,3],[4,5,6]]`은 두 겹이니까 2차원이에요.

### 왜 굳이 상자에 담나?

파이썬 리스트로도 숫자를 담을 수 있는데 왜 텐서를 쓸까요? 이유는 세 가지예요.

1. **한 번에 계산**: 리스트는 `for`문으로 하나씩 더해야 하지만, 텐서는 `a + b` 한 줄로 수천 개를 한꺼번에 더해요.
2. **빠른 장치로 옮기기**: 텐서는 GPU 같은 가속기로 통째로 보낼 수 있어요.
3. **자동 미분**: 나중에 기초편 C에서 보겠지만, 텐서는 "이 숫자를 조금 바꾸면 결과가 얼마나 바뀌나"를 자동으로 계산해 줘요. 학습의 핵심이에요.

### 상자를 만드는 여러 방법

숫자를 직접 적는 것 말고도, 자주 쓰는 모양을 바로 만드는 함수가 있어요.

```python
torch.zeros(2, 3)      # 0으로 채운 2×3
torch.ones(2, 3)       # 1로 채운 2×3
torch.arange(6)        # tensor([0, 1, 2, 3, 4, 5])
torch.manual_seed(0)   # 무작위를 매번 똑같이 (실험 재현용)
torch.rand(2, 3)       # 0~1 사이 무작위 2×3
torch.randn(2, 3)      # 평균 0, 표준편차 1인 무작위 2×3
```

신경망의 가중치는 처음에 `randn`처럼 무작위로 시작해요. 그래서 `torch.manual_seed`를 걸어 두면 매번 같은 결과를 얻을 수 있어서 디버깅이 편해요.

## 2. shape: 상자의 칸 수

![2×3 행렬에 행 2개(dim 0), 열 3개(dim 1) 괄호를 붙인 그림](/assets/img/posts/2026-10-31-pytorch-00a/fig02.jpg)

*그림 2. `shape`는 "각 방향으로 칸이 몇 개인가"를 바깥쪽부터 적은 목록이에요. 2×3 행렬은 `[2, 3]`이고, 앞의 2가 dim 0(행), 뒤의 3이 dim 1(열)이에요.*

텐서에서 **가장 중요한 정보 하나**를 고르라면 `shape`예요. PyTorch 에러의 절반 이상이 "shape이 안 맞아요"라서, 코드를 짤 때 항상 shape을 먼저 확인하는 습관을 들이면 좋아요.

```python
m = torch.tensor([[1, 2, 3], [4, 5, 6]])
print(m.shape)       # torch.Size([2, 3])
print(m.shape[0])    # 2  ← 행 개수
print(m.shape[1])    # 3  ← 열 개수
print(m.numel())     # 6  ← 칸 전체 개수
```

### dim이라는 말에 익숙해지기

PyTorch 함수들은 자주 `dim=0`, `dim=1` 같은 인자를 받아요. **dim은 "어느 방향으로"라는 뜻**이에요. 2차원에서는

- `dim=0` → 위아래 방향 (행을 따라)
- `dim=1` → 좌우 방향 (열을 따라)

이라고 기억하면 돼요. 3절에서 `sum(dim=1)`로 직접 확인해 볼게요.

### 모양 바꾸기: reshape

칸 개수만 같으면 상자 모양을 바꿀 수 있어요.

```python
x = torch.arange(6)        # [0 1 2 3 4 5], shape (6,)
print(x.reshape(2, 3))     # 2행 3열
print(x.reshape(3, 2))     # 3행 2열
print(x.reshape(-1, 2))    # -1은 "알아서 계산해 줘" → (3, 2)
```

`reshape(4, 2)`처럼 칸 수(8)가 원래(6)와 다르면 에러가 나요. "숫자는 그대로, 줄 바꿈 위치만 바꾼다"고 생각하면 돼요.

### 실제 데이터의 shape 감 잡기

| 데이터 | 흔한 shape | 뜻 |
|---|---|---|
| 사람 32명의 [키, 몸무게, 나이] | `(32, 3)` | 32개 샘플 × 3개 특징 |
| 28×28 흑백 사진 64장 | `(64, 1, 28, 28)` | 장 × 채널 × 세로 × 가로 |
| 단어 10개짜리 문장 8개 | `(8, 10)` | 문장 × 단어 위치 |

맨 앞 숫자는 거의 항상 **배치(batch)**, 즉 "한 번에 몇 개를 처리하나"예요. 신경망은 샘플을 하나씩이 아니라 묶음으로 처리해요. 이 관례는 기초편 B에서 계속 나와요.

## 3. 인덱싱: 원하는 칸 꺼내기

![같은 2×3 행렬에서 x[0], x[:,1], x[1,2]가 고르는 칸을 금색으로 칠한 그림](/assets/img/posts/2026-10-31-pytorch-00a/fig03.jpg)

*그림 3. 대괄호 안에 "행, 열" 순서로 번호를 적어요. 번호는 0부터 세고, `:`는 "그 방향 전부"라는 뜻이에요.*

```python
m = torch.tensor([[1, 2, 3],
                  [4, 5, 6]])
print(m[0])        # tensor([1, 2, 3])   첫 행
print(m[:, 1])     # tensor([2, 5])      두 번째 열
print(m[1, 2])     # tensor(6)           한 칸
print(m[1, 2].item())  # 6               파이썬 숫자로 꺼내기
```

`.item()`은 칸이 하나뿐인 텐서를 평범한 파이썬 숫자로 바꿔 줘요. 나중에 학습 중에 loss 값을 출력할 때 매번 쓰게 돼요.

### 슬라이싱: 범위로 자르기

파이썬 리스트처럼 `시작:끝`으로 범위를 자를 수 있어요. 끝 번호는 포함되지 **않아요**.

```python
x = torch.arange(10)
print(x[2:5])     # [2, 3, 4]
print(x[:3])      # 앞에서 3개
print(x[-2:])     # 뒤에서 2개
print(m[:, 1:])   # 모든 행의, 두 번째 열부터 끝까지 → [[2,3],[5,6]]
```

### 조건으로 고르기 (마스크)

"3보다 큰 것만" 같은 조건도 바로 쓸 수 있어요.

```python
print(m > 3)       # [[False, False, False], [True, True, True]]
print(m[m > 3])    # tensor([4, 5, 6])
```

`m > 3`은 같은 모양의 참/거짓 상자를 만들고, 그걸 다시 대괄호에 넣으면 참인 칸만 뽑혀요. 데이터에서 이상한 값을 걸러낼 때 아주 많이 써요.

## 4. 기본 연산: 칸끼리 짝지어 계산

![[1,2,3] + [10,20,30] = [11,22,33], 그리고 [1,2,3] × 2 = [2,4,6]을 보여 주는 그림](/assets/img/posts/2026-10-31-pytorch-00a/fig04.jpg)

*그림 4. 모양이 같은 두 상자를 더하면 같은 위치끼리 더해져요(원소별 연산). 숫자 하나를 곱하면 모든 칸에 똑같이 곱해져요(브로드캐스팅).*

```python
a = torch.tensor([1., 2., 3.])
b = torch.tensor([10., 20., 30.])

print(a + b)    # [11, 22, 33]
print(a - b)    # [-9, -18, -27]
print(a * b)    # [10, 40, 90]   ← 행렬 곱이 아니라 칸끼리 곱!
print(a / b)    # [0.1, 0.1, 0.1]
print(a * 2)    # [2, 4, 6]
print(a ** 2)   # [1, 4, 9]
```

주의할 점 하나: `*`는 **칸끼리 곱**이에요. 수학 시간에 배운 행렬 곱은 `@`로 따로 써요. 행렬 곱은 신경망의 심장이라 기초편 B에서 그림으로 자세히 볼게요. 지금은 "`*`는 칸끼리, `@`는 행렬 곱"만 기억하세요.

```python
W = torch.tensor([[1., 0., 1.],
                  [0., 2., 0.]])
x = torch.tensor([2., 1., 3.])
print(W @ x)    # tensor([5., 2.])  ← 다음 글의 주인공
```

### 모으기: sum, mean, max

여러 칸을 하나로 요약하는 연산도 많이 써요.

```python
print(a.sum())     # 6
print(a.mean())    # 2
print(a.max())     # 3
m = torch.tensor([[1, 2, 3], [4, 5, 6]])
print(m.sum())          # 21     전체
print(m.sum(dim=0))     # [5, 7, 9]   위아래로 접기 (열마다 합)
print(m.sum(dim=1))     # [6, 15]     좌우로 접기 (행마다 합)
```

`dim=1`로 합하면 그 방향(열 방향)이 **사라지면서** 한 줄로 접혀요. shape이 `(2, 3)` → `(2,)`가 되는 거죠. "dim을 지정하면 그 방향이 접힌다"고 기억하면 헷갈리지 않아요. 기초편 C에서 loss를 계산할 때 `mean()`이 바로 이 역할을 해요.

### 브로드캐스팅: 작은 상자가 퍼지는 규칙

모양이 다른 두 상자도 계산할 수 있는 경우가 있어요.

```python
m = torch.tensor([[1, 2, 3], [4, 5, 6]])   # (2, 3)
row = torch.tensor([100, 200, 300])         # (3,)
print(m + row)
# [[101, 202, 303],
#  [104, 205, 306]]
```

`row`가 행마다 복사된 것처럼 동작했어요. 이게 **브로드캐스팅**이에요. 규칙은 "뒤쪽 차원부터 맞춰 보고, 크기가 1이거나 없는 쪽은 늘려서 맞춘다"예요. 신경망에서 편향(bias)을 더할 때 바로 이 규칙을 써요. 배치 32개 모두에 같은 bias를 더하는 거죠.

맞출 수 없으면 에러가 나요.

```python
torch.ones(2, 3) + torch.ones(2)   # 에러! 뒤 차원 3과 2가 다름
```

에러 메시지에 `The size of tensor a (3) must match the size of tensor b (2)`가 보이면 "아, 브로드캐스팅이 안 됐구나" 하고 shape을 출력해 보세요.

## 5. dtype과 device: 상자에 붙은 이름표

![숫자 상자 옆에 'dtype: float32', 'device: cpu' 이름표가 화살표로 붙어 있는 그림](/assets/img/posts/2026-10-31-pytorch-00a/fig05.jpg)

*그림 5. 모든 텐서에는 이름표가 두 개 붙어 있어요. **dtype**은 숫자의 종류(소수냐 정수냐, 얼마나 정밀하냐), **device**는 숫자가 사는 곳(CPU냐 GPU냐)이에요.*

### dtype: 숫자의 종류

```python
print(torch.tensor([1, 2]).dtype)      # torch.int64   (정수)
print(torch.tensor([1., 2.]).dtype)    # torch.float32 (소수)
x = torch.tensor([1, 2])
print(x.float().dtype)                 # float32 로 변환
```

신경망은 대부분 **`float32`** 로 계산해요. 가중치를 조금씩 바꿔야 하는데 정수는 0.001만큼 움직일 수 없으니까요. 숫자 `1`과 `1.`(점 하나 차이)이 다른 dtype이 된다는 점을 꼭 기억하세요. 초보자가 자주 만나는 에러가 "정수 텐서에 소수 연산을 했다"예요.

| dtype | 쓰임 |
|---|---|
| `float32` | 기본. 학습과 추론 대부분 |
| `float16`, `bfloat16` | 메모리를 아끼고 싶을 때 |
| `int64` | 개수, 번호(정답 클래스 번호 등) |
| `bool` | 마스크(참/거짓) |

### device: 숫자가 사는 곳

```python
device = "cuda" if torch.cuda.is_available() else "cpu"
x = torch.tensor([1., 2., 3.]).to(device)
print(x.device)
```

GPU가 있으면 `cuda`, 없으면 `cpu`가 나와요. 지금 단계에서는 CPU로 충분해요. 다만 **규칙 하나**만 기억하세요. **같이 계산하는 텐서는 같은 device에 있어야 해요.** 하나는 CPU, 하나는 GPU에 있으면 에러가 나요.

## 정리

- 텐서는 **숫자 상자**. 차원(`ndim`)과 모양(`shape`)으로 생김새를 알아요.
- 인덱싱은 `[행, 열]`, 0부터, `:`는 전부.
- `+ - * /`는 **칸끼리**, `@`는 **행렬 곱**.
- `sum(dim=…)`은 그 방향을 접어요. 브로드캐스팅은 작은 상자를 퍼뜨려요.
- 이름표 두 개: **dtype**(숫자 종류)과 **device**(사는 곳). 같이 계산하려면 맞춰야 해요.

다음 글에서는 이 상자 두 개를 `@`로 곱하는 것, 즉 **신경망 한 층(Linear)** 이 무슨 일을 하는지 그림으로 볼게요.
